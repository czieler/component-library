
## Top navigation pattern

Use Top Navigation when an application benefits from reclaiming horizontal content space from a persistent sidebar. Nested desktop menus open on hover/focus and remain keyboard accessible; the same configuration becomes a mobile drawer on narrow screens. Keep product-specific routing, authorization, labels, and branding in the consuming application.

Use icons consistently within each menu group. The shared top-navigation implementations reserve the same icon column in desktop flyouts and mobile submenus so sibling labels stay aligned.
